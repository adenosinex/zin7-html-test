① 文件结构

第一行必须是表头，从第二行起为数据；至少需要 1 行表头 + 1 行数据。 编码建议使用 UTF-8，否则中文可能乱码。

分隔符支持 英文半角逗号 , 与 制表符 Tab（Excel 直接复制粘贴就是 Tab），程序会自动识别。

② 字段要求

列的顺序不限，字段名不区分大小写、忽略空格与引号。识别规则如下：

字段是否必填可识别的写法（别名）说明
用户名 必填 用户名 / 网名 / username / name / 昵称 / 账号 / 博主 为空的行会被自动跳过；同时用于生成头像；点击卡片上的用户名会新窗口打开 http://192.168.31.124/?search=用户名
文案数量 可选 文案数量 / 文案数 / 数量 / count / posts / 作品数 / 视频数 非数字按 0 处理，用于统计与徽标显示
总点赞 可选 总点赞 / 点赞数 / 点赞 / 总赞 / 获赞 / likes / like 超大数值自动转为「万 / 亿 / 科学计数法」显示
日期范围 可选 日期范围 / 时间范围 / 日期 / 时间 / date / daterange / range 原样显示在卡片上，留空则不显示该行
标签 可选 标签 / 话题 / 话题标签 / tags / tag 按 、 ， , ； ; 拆分，自动去掉开头的 #（最多 6 个）

⑤ 书写注意事项

  • 字段内容包含 逗号、换行 或 双引号 时，请用双引号把整个字段包起来。
  • 字段内的双引号需写成两个双引号转义，例如："他说""你好""就走了"。
  • 表头与数据行之间不要插入空行或注释行。
  • 使用逗号分隔时请使用英文半角逗号 ,（中文顿号、逗号只用于标签内部拆分）。
  • Excel 导出时选择「CSV UTF-8（逗号分隔）」，或直接在 Excel 中框选复制、粘贴到输入框（Tab 分隔）。

⑥ 跳转说明

用户名会被 URL 编码后拼接到搜索链接，空格 → %20，中文/Emoji 也会自动编码， 因此含特殊字符的用户名同样可以正常跳转。

⑦ 本地保存说明

  • 每次成功解析后，原文会存入浏览器的 localStorage，下次打开自动恢复。
  • 「解析并生成卡片」与「上传文件」都会自动保存，覆盖上一次的记录。
  • 每页条数的偏好也会一并保存，下次打开沿用。
  • 点「清空」会同时清除页面数据与本地记录；点「清除本地记录」只清除存储，不影响当前展示。
  • 数据仅保存在本机当前浏览器中：换浏览器、换设备不会同步；清除浏览器数据会一并丢失。
  • 浏览器 localStorage 通常只有 约 5MB，数据过大时会保存失败并给出提示。
