巫山房子特点：陡坡岩层与库区水文约束下的竖向营建机制

巫山地处大巴山、巫山、七曜山三大山脉交汇处，长江横切背斜形成深切峡谷。巫山房屋并非单纯的美学形式，而是对「无平地可用、三叠系灰岩顺层滑坡风险、30米库区水位消落、峡江高湿静风」四大硬约束的工程学回应——从淹没前老城的“半坡穿斗吊脚楼”，演变为175米蓄水线之上的“抗滑桩基+双首层退台立体住区”。

    03 / MICROCLIMATE & ENVELOPE

    巫峡微气候响应：为何“下架空、中冷巷、上挑檐”不可替代

    MECHANISM A // 湿热瘴气阻断

    底层架空（吊脚/架空转换层）

    巫山河谷年均风速仅 1.2–1.6m/s，水库蓄水后水面展宽，近地层水汽饱和度极高，且三叠系灰岩裂隙常有季节性渗水。若首层直接贴地满铺，室内地坪极易结露返潮、滋生霉菌白蚁。

    因果链：高湿渗水坡面 → 架空层脱离地面 ≥2.2m → 坡风穿堂带走湿气 + 避免大规模土石方开挖
    MECHANISM B // 热压拔风组织

    高密度爬坡冷巷与天井

    夏季巫山河谷极端高温可达 41°C 以上，且静风率超过 45%。房屋顺等高线密集跌落排布时，建筑间距窄、山墙高耸遮挡直射阳光，形成阴凉的纵向爬坡窄巷（传统梯道巷）。

    因果链：江面冷空气下沉 + 坡顶受热上升 → 狭窄梯巷形成烟囱热压差 → 无风天自发产生爬坡穿堂风
    MECHANISM C // 暴雨径流疏导

    深挑重檐与急坡阶梯排水沟

    巫山年降水量约 1050mm 且多短时强对流暴雨，陡坡汇水速度是平原的 4–6 倍。传统民居出檐深达 0.9–1.5m 保护竹木泥墙；现代新城则在每一级退台内侧设消能跌水暗沟。

    因果链：陡坡瞬时山洪汇流 → 坡顶截水沟 + 层层跌水消能井 → 严防雨水灌入顺层岩石节理诱发滑坡
    04 / EVOLUTION MATRIX

    两代巫山房屋工程参数对比（淹没前老城 vs 175m移民新城）

    核心维度 传统巫山峡江民居（1990年代以前老城） 现代巫山库区山地建筑（三峡蓄水搬迁后） 底层演进动因与约束变化
    选址标高区间 海拔 85m – 165m（紧贴枯水期航道与码头栈道） 海拔 182m – 380m（严守175m蓄水线+风浪安全超高） 三峡成库淹没全部河谷缓坡阶地，城市被迫整体上移至山腰陡坡
    基础与护坡体系 天然基岩凿窝置柱础、干砌/浆砌青石条堡坎 深埋矩形抗滑桩（深20–35m）+ 预应力锚索框架梁 新址多位于古滑坡堆积体或顺层灰岩坡，浅基础无法抵抗库水升降诱发的蠕变
    主体结构形制 巴渝穿斗式木构架、前吊后靠、竹编夹泥墙（轻质柔韧） 钢筋混凝土异形柱/掉层框架-剪力墙结构、退台错层 人口容积率需求提升5倍以上，多层/高层化必须解决上下刚度突变抗震难题
    入户与交通组织 单一石板爬坡梯道入户（如老城朝云梯、大云梯），纯步行 盘山车行环道 + 建筑内部公共电梯厅充当城市垂直交通 + 屋顶天桥双首层 “建筑即城市道路”：坐电梯下1楼是下街，上8楼出天桥是上街公交站
    立面与屋顶特征 小青瓦双坡顶、悬挑木栏杆外廊（吊脚楼群层叠肌理） 坡屋顶重檐封顶、深凹观江阳台、灰白墙配栗壳色挑檐（新巴渝风貌） 巫山高差使下一栋的屋顶成为上一栋的近景俯视面，“第五立面（屋顶）”颜值与防水至关重要
