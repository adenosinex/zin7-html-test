ft · 文件整理 — 用法

把文件夹里的文件按规则整理：flatten 把子目录里的文件集中到根目录；group 每 2 个一组分进“分组001、分组002……”文件夹。先打印预览，确认后执行；目标重名时自动加“ (n)”后缀，绝不覆盖已有文件。

1. 下载客户端

下载 toolrun.py（Python 3，只用标准库），放到 PATH 里，或在你的电脑上用 python toolrun.py 运行。

2. 配 token

浏览器登录面板后，打开 lightapi 页，地址栏 ?token= 后面的值就是令牌，把它保存到 %USERPROFILE%\.config\toolrun\token（不要把令牌发给任何人）。也可以设环境变量 TOOLRUN_TOKEN。

3. 跑起来

toolrun list
toolrun ft D:\下载
toolrun ft flatten D:\下载
toolrun ft group D:\下载 --yes

不加 --yes 时先打印预览并询问确认；加 --yes 直接执行。工具代码缓存在 %USERPROFILE%\.local\share\toolrun\<简称>\，按版本号判断是否更新；强制重拉用 toolrun <简称> --update。
