技术路线：后训练蒸馏的三条路

2026 年国产模型的训练范式正在分化，核心分歧在于如何融合多领域能力。(citation:7)

Qwen：强模型教小模型

大模型已经花大量计算获得 reasoning 等能力，小模型通过 Off-policy → On-policy 蒸馏直接继承，无需重新跑完整 RL。(citation:7) 核心价值：模型压缩。

GLM：历史 Checkpoint 防遗忘

连续做 Reasoning RL → Agentic RL → General RL 时，后面训练可能让前面能力退化。GLM 保存之前训练阶段的 checkpoint 作为 Teacher，用 Cross-stage Distillation 重新巩固所有能力。(citation:7)

Kimi / MiMo / DeepSeek：多专家融合

先分别在 Math、Coding、Agent 等领域做 RL 得到多个专家 Teacher，再通过 MOPD 蒸馏进一个统一 Student。(citation:7) 内部分歧在于 KL 粒度：Kimi 偏 Sampled Token 追求低成本，DeepSeek 用 Full-Vocabulary 追求更稳定梯度，MiMo 统一在 Reverse-KL 框架下可切换近似方式。

关于排名的解读方式

Arena 平台的 ELO 分差在 ±30 分以内通常被视为统计误差范围内的接近。(citation:2) 这意味着榜单上排名紧挨着的模型，实际用户体验差别可能微乎其微。在这个区间里，"谁更好"远不如"谁更适合你的任务"重要。

  • 写代码、做前端、跑 Agent：Kimi K3 是当前国产验证成绩最好的选择。(citation:4)
  • 中文写作、超长文档、综合办公：Qwen3.8-Max 更稳。(citation:4)
  • 高难度推理和数学：DeepSeek V4 Pro 实测推理单项国产最强。(citation:4)
  • 预算敏感的高频调用：DeepSeek V4 Flash 性价比没有对手。(citation:4)
  • 安全漏洞与编程专项：GLM-5.3 在 CyberGym 登顶第一。(citation:11)
  • 本地部署、数据不出内网：可选开源的 Kimi K3、GLM-5.2 或 Qwen 家族。(citation:4)
判断任何"第一"宣称的三个问题：这个第一是在哪个坐标系里？这个坐标系是谁定义的？同一坐标系里排第二第三的是谁？(citation:4) 每家厂商的说法在技术上都不算撒谎，它们只是选择了对自己最有利的坐标系——切法无穷，"第一"也无穷。
