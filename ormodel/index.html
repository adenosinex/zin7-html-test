强在模型本身，不是供应商多

供应商多是结果，不是原因。周榜前 20 名一周烧掉 163.68T tokens，头部模型几乎都收敛到同一套内在配方——稀疏 MoE（总参数百 B、激活仅 8–55B）＋混合稀疏/线性注意力＋ 1M 上下文＋ FP8/FP4 量化，同时压低每 token 的计算和 KV 显存，provider 才有可能把价格压到 $0.1–0.6。开放权重让更多人能复制这套配方、参与压价，是放大器，不是发动机。这页逐个深挖 17 个模型的许可证、参数、架构、部署成本和真正强弱项。

01排名：先把口径说清楚

排行榜量的是「谁被用得多」，不是「谁更好」。下面三件事不先说清，后面所有数字都会被误读。

统计口径（OpenRouter 官方说明）

  • 按 tokens 排名（输入 + 输出之和），不是请求数、不是花了多少钱、不是质量分。官方明确说排行榜不衡量用户数、支出或 benchmark 成绩；模型的啰嗦程度和 tokenizer 差异也会影响 token 总量。
  • 按模型变体分别排名：免费变体（:free）单独算；用户设为私有的请求排除在外。窗口为过去 1 / 7 / 30 天，均截至最新完整 UTC 日；下文以周榜（过去 7 天）为准，单日波动太大。
  • 开放权重≠开源≠能自托管：多数只公开权重，许可证从 MIT/Apache 2.0 到自定义附条件许可差别极大；权重 252GB–1.56TB 决定了自托管门槛，总参数决定显存、激活参数决定每 token 计算，两者必须分开看。
  • 价格有两套口径（次要因素）：厂商端价（模型作者自己 endpoint 的价）和 OpenRouter 最低价（几十家第三方 provider 里最便宜的一家），同一模型可差 10–25 倍。本页两个都给，不混用。
  • 速度是「最优 provider 的 P50」，不是你默认路由到的体验；不同 provider 之间速度可差 2–5 倍。DeepSeek 1017 标称的 725 tok/s 来自最贵的 Ultrafast endpoint，普通 provider 约 130–276 tok/s。
  • 流量主要由 agent 应用驱动，不是个人聊天：DeepSeek 1017 的最大来源是 Hermes Agent（8.21T）、Claude Code（5.69T）、pi（5.63T）；Opus 5.5 的最大来源 Claude Code 一家就贡献了 14.2T。

02内在规格：开放权重、参数与架构决定部署成本

先看模型本身，再看价格。真正压低每 token 成本的是三件事：激活参数小（每 token 只算 8–27B，而不是总参的数百 B）、KV 缓存压缩（混合稀疏/线性注意力让 1M 上下文的并发显存可控）、量化友好（原生 FP8/FP4）。下表是 17 个模型的内在规格总表；价格与 provider 数量放在表后，只作结果参考。来源标注：厂商自评与独立第三方（AA 等）严格分开，AA 在 2026-10-27 推出 v5.0 重标尺度，不同版本分数不可直接比较。

假设检验：「开放 → 便宜部署 → 低价 → 高用量」只对了一半

  • 环节 1 打折——开放≠个人能便宜部署：DeepSeek 1017 约 510GB、GLM Flash FP8 约 331GB、Hy4 FP8 约 770GB、Kimi 1.56TB、Step 5 FP8 约 650GB。能跑它们的只有大集群，不是普通用户。
  • 环节 2 打折——开放≠低价：Kimi 开放权重却卖 $2/$10（104B 激活），与闭源 Sonnet / GPT-6.1 Sol 同档，一周只有 4.12T；反过来闭源 GPT-6 Luna、Claude Haiku 5.5 都是 $0.10/$0.50，比多数开放模型还便宜。
  • 环节 3 打折——免费≠高用量：Nemotron 两款 $0 免费模型只排第 17、18 名（2.93T / 2.91T），远低于 DeepSeek 1017 的 56.04T。价格降到 0 之后，能力天花板和生态入口成为瓶颈。
  • 共同配方才是底层原因：2026 年 8–10 月这批模型几乎全部是稀疏 MoE + 混合注意力 + 1M 上下文 + 原生视觉 + 默认深度思考 + FP8/FP4。没有这套配方，光开放也冲不上榜（见第 05 节反例）。

05核心问题：它们靠什么活着，没被同价位替代

能留在榜上的模型，各有一样竞品拿不走的内在东西——不是「40 家 provider」，而是「同价位 agent 编码最强」「KV 只有 890 字节/token」「1M 检索 98.1%」这类写在权重和架构里的特点。闭源高排名者靠的则是能力天花板、生态入口和每任务成本，同样是内在账，不是供应商数量。

为什么「同价位竞品」结构性打不赢——内在版

1激活参数决定每 token 的硬成本

MoE 每 token 只算激活的那部分：8–18B 激活的 DeepSeek/GLM Flash/MiMo 能卖 $0.28–0.60 输出价，49–104B 激活的 Hy4/Kimi/Nemotron Ultra 即便开放权重也压不下来。竞品想更便宜，必须先改架构，不是多找几家供应商。

2KV 缓存决定 1M 上下文能不能赚钱

长上下文的瓶颈是 KV 显存，不是参数。DeepSeek 的 CSA2 把全局 KV 压到 890B/token（约上代 1/4），GLM 的线性注意力层把 KV 降 4.44 倍，MiniMax 全稀疏注意力只读最优 16 个块——谁压缩得狠，谁的长任务并发就便宜。

3量化友好度决定权重能不能塞进更少的卡

原生 FP8/FP4（DeepSeek FP4 专家与 KV、MiniMax FP4 专家、Kimi MXFP4 量化感知训练）让数百 GB 权重在出厂时就已压缩；不支持低精度友好的架构，部署成本直接翻倍。

4开放权重是放大器：让配方被复制和压价

MIT/Apache 的模型（DeepSeek、GLM Flash、MiMo）任何 provider 都能部署，价格被竞争压到官方价以下；但许可证一旦附条件（StepFun、MiniMax、Kimi、GLM 5.3 均有收入门槛或审查义务），或权重缩水、激活过高，放大效应立刻打折。

5闭源靠能力上限与每任务成本，不靠开放

Opus 靠综合智能上限，Sonnet 靠 TB 4.0 家族第一+半价，GPT-6.1 Sol 靠每任务 $1.82（Opus 的 1/7），Luna 靠每任务 $0.07。它们的共同点是「某个内在指标好到价差被抵消」，与供应商数量无关。
