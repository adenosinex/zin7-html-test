2 什么性质：两个「云电脑」别混为一谈

最大的混淆点就在这里：TeleAgent 里的云电脑，和天翼云单独卖的云电脑，是两条不同的获得路径。

TeleAgent 星辰超级智能体

主体产品 · 桌面级通用 AI 智能体
  • 做什么：理解自然语言任务 → 自主规划 → 调用技能/连接器/MCP → 操作文件与软件 → 交付文档、表格、PPT、代码、网页应用、调研报告。
  • 运营方：中电信人工智能科技（北京）有限公司；底座为星辰大模型（备案号 Beijing-XingChen-202404280001），框架据官方称全自研；也可自填 API Key 接入百炼、DeepSeek、Kimi Code、MiniMax。
  • 形态：桌面端（Win 10 1809+ / macOS 13+，另有银河麒麟/统信 UOS 信创版、鸿蒙 PC 客户端）、网页端、移动端（Android 已发，iOS 称开发中）。三端协同、记忆同步。
  • 本地优先≠不出电脑：文件默认落本地工作空间，但推理走云端模型，指令与引用文件内容会发到云端处理。

「天翼云电脑」在 TeleAgent 里

一种运行模式 · 不是独立产品
  • 发起任务时二选一：「本地运行」（关机则定时任务跳过、长任务中断）或「云电脑运行」（任务在分配的云电脑上跑，可关本地设备）。网页端只能云端运行。
  • 资源从哪来：用户协议原文——云端运行时「即时分配第三方服务商提供的云计算资源」。即不是自有固定机房直供，而是按需分配。
  • 能手动操作：云电脑「运行中」时可在新标签页打开 Windows 桌面，像普通电脑一样装软件、理文件，Agent 也在里面自主操作；网页端文件统一存在云电脑 D 盘 data 目录。右上角按钮是「云电脑状态：连接中/运行中」，未见字面为「启动天翼云电脑」的按钮，可能是版本/入口表述差异。

另有一套独立产品：「天翼AI云电脑（公众版/政企版）」是天翼云单独卖的云桌面，镜像市场预装 TeleAgent、OpenClaw、WorkBuddy 等。地方电信宣传的「天翼AI云电脑 + TeleAgent」组合，是把 Agent 装进你自购的云电脑，与网页版「平台分配一台」不是一回事。计费体系也完全不同（见下节），网上很多「免费额度烧得快」的吐槽其实指向这一套。

👍 主要好评

  • 规划细致、不编造：横评中任务拆解认真；材料数字矛盾时不擅自取舍、双写标注待核实；ROI 数据不足直接写「无法计算」，零编造；私事内容不漏进正文。
  • 端到端跑得通：掘金实测工单自动分类落盘、周报数字与台账一致（受理 42、办结 39、在途 3、回访 15）、技能孵化与自建 MCP 全部跑通，认为对政企/运营商团队友好。
  • 代码稳定：微博用户试用称「代码稳定性超出预期」。
  • 生态与性价比：技能广场 5 万+；连接器覆盖 WPS/腾讯文档/飞书/钉钉/高德；可换第三方模型；IT 时报认为其计费规则下复杂任务「花费相对更划算」，且官方公示了分场景消耗区间。

👎 主要投诉与质疑

  • 交付不稳（最反复）：转 Word 挂起、独立文件未生成、承诺与实际不符；横评结论「指望它稳定交付正式文档的建议再等等」。
  • 营销味重：知乎同期出现《电信 TeleAgent 夯爆了》等从头夸到尾的帖子，被独立作者明确标注为软广、「一律当营销文案处理」；B 站 4.4 万播放的是官方教程，非自发评测。
  • 云电脑客户端体验差：磁盘映射关不掉、还盘卡死、网页/桌面入口分裂且登录报错、自动关机策略不透明要找保活程序。
  • 免费额度不耐用（多指向独立云电脑/OpenClaw 体系）：2500 万 Token 按单轮 8–9 万消耗只够轻度玩 1–2 周，有人一月烧 4474 万、重度用户一月 87 亿 Token 花 604 元，后台心跳闲置也能烧掉百万级。TeleAgent 侧则有「复杂任务一次数百积分」的提醒。
  • 计费/绑定争议（针对天翼云电脑，非 TeleAgent 网页版）：有用户发现 59 元校园卡套餐默认绑 30 元/月云电脑基础版；「关客户端≠云端关机」，不手动关机按小时一直计费。
  • 隐私边界：「本地优先」宣传与推理走云端的落差；工作空间授权范围大，建议权限只选「允许一次」，敏感文件不要喂给任何云端推理 Agent。官方页面本身也提示「不要将涉密数据交给 TeleAgent 处理」。

情绪总判：混合偏谨慎。只看官方与通稿几乎全是正面；只看独立实测与论坛，则是「能力认可、稳定性与营销存疑」。没有证据支持「大多数用户满意」或「大多数不满」任一结论——样本太小、营销声量太大。
