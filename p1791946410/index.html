01 · 六层框架：从理解到行动

🎯
01 / 目标层

什么值得追求？

效用 · 价值排序 · 底线约束

先确定真正的目标，避免把收入、时长等指标当成最终价值。

🔎
02 / 认知层

什么是真的？

贝叶斯 · 奥卡姆 · 基础概率

从一般情况出发，以证据更新判断；不无故增加复杂假设。

⚙️
03 / 解释层

为什么会这样？

激励约束 · 有限理性 · 交易成本

先看收益、成本、资源、权限、信息与沟通阻力。

⚖️
04 / 选择层

做什么更合算？

机会成本 · 比较优势 · 边际分析

每个“要”都有“不要”；比较的是替代方案和相对代价。

🤝
05 / 互动层

别人会怎么回应？

博弈论 · 信息不对称 · 委托代理

考虑对方的激励、策略、信任、声誉以及规则设计。

🔁
06 / 进化层

怎样越做越对？

反馈 · 复利 · 实物期权 · 古德哈特

先低成本验证，再调整模型；重视长期后果和选择权。

02 · 九个高复用原理

🪒
奥卡姆剃刀 解释力相当时，少假设优先；不是永远选最简单的故事。
📊
贝叶斯 + 基础概率 不要默认自己或眼前情况特殊；新证据来了就更新。
⏳
稀缺性 + 机会成本 时间、精力、金钱都稀缺；问“放弃的最好选项是什么？”
🧭
比较优势 不是谁绝对更强，而是谁做这件事的相对机会成本更低。
💡
激励与约束 先看行为环境，再谈人品、性格和特殊动机。
💬
交易成本 + 信息不对称 沟通、搜索、核实与协作都有成本；降摩擦常比讲道理有效。
♟️
博弈与机制设计 行动会引起回应；优先创造让合作自然发生的规则。
🌿
动态反馈 + 复利 一次有效不等于长期有效；关注累积、反作用和路径依赖。
🛡️
选择权 + 风险管理 不确定且不可逆时，先用小试验买信息、留退路。

03 · 通用决策七问：遇事从这里开始

01 目标是什么？ 结果 / 指标 / 底线
02 一般会怎样？ 基础概率 / 同类案例
03 最简解释？ 少加特殊假设
04 驱动因素？ 激励 / 约束 / 摩擦
05 代价与优势？ 机会成本 / 替代方案
06 他人如何反应？ 博弈 / 信任 / 二阶效应
07 如何验证？ 小步试验 / 反馈更新

04 · 同一件小事，五个视角

例子：别人没有及时回复消息。不要立即解释成“针对我”。

① 简化解释

可能忙、忘了、优先级低；别先发明复杂心理剧。

② 基础概率

先用相似情境的常见原因作初始判断。

③ 激励约束

回复是否有收益？是否需要承担责任？有权限吗？

④ 降低摩擦

改成是/否问题，提供选项，降低回复成本。

⑤ 实验更新

降低成本后仍持续回避，再提高“不愿回应”的判断权重。

05 · 三个防止“理性失控”的护栏

⚠️ 古德哈特定律

指标一旦变成追逐目标，就可能失真。 不要把收入、效率、数量误认为全部价值。

自问：我是在优化真正的结果，还是在刷指标？

🔐 实物期权

信息不够、错误代价高时， 分阶段行动可保留未来选择权。

自问：能不能用更小、可逆的方式先试一次？

🌊 复杂系统

局部最优可能伤害整体； 短期收益可能创造长期负反馈。

自问：如果把这个行为重复三年，会发生什么？

06 · 记住三个不同问题

什么是真的？ 证据 / 先验 / 简化假设
为什么发生？ 激励 / 约束 / 博弈 / 反馈
什么值得做？ 价值 / 机会成本 / 风险
结构性解释优先，个体差异作为增量， 特殊解释需要额外证据。

使用边界：通用模型只是起点，不是拒绝例外的理由。 证据充分时要接受复杂解释； 价值取舍也不能单靠经济效率决定。
