客户端 hashscan.py — 用法

直接运行客户端就进扫描，一共两步：步骤 1 输入要扫描的目录路径；步骤 2 选项目（列出已有项目，输入序号选用，上次用过的直接按 Enter）。然后扫描上传，重复文件（和库重复 + 本批内重复）列出清单、输入 y 确认后移到目标文件夹的子文件夹 duplicates。扫描时显示进度条。自体去重：同一批里内容相同的文件也算重复，只保留第一个。头部大小等额外配置只在首次运行时问一次，存进配置文件，以后直接用；不喜欢就删除配置文件重新设置。项目列表在后台预取，输入路径时不卡顿；结束后停在完成提示、按 Enter 再退出，双击运行窗口不会一闪而过。

只算文件头部 hash：默认只取每个文件开头 1MB 算 SHA-256（小于 1MB 取全部），速度快，但头部相同、后面不同的两个文件会被误判为重复——模式 2 移动前请看清确认清单。头部大小可用 --head-size 改（单位 MB）。

1. 下载客户端

下载 hashscan.py（Python 3，只用标准库），在你的电脑上用 python hashscan.py 运行。

2. 配 token（第一次运行时直接问你要）

第一次运行客户端，它会直接问你要令牌：浏览器登录面板后，打开 lightapi 页，把地址栏的地址整个粘贴过去就行（带 ?token= 的那串），也可以只贴 token 本身。脚本会自动验证，通过后自动保存，以后不用再输（不要把令牌发给任何人）。也可以事先设环境变量 HASHSCAN_TOKEN。

3. 跑起来

python hashscan.py scan D:\照片 --project 照片库
python hashscan.py scan D:\备份 --project 照片库 --dup-dir D:\重复文件
python hashscan.py scan D:\视频 --project 视频库 --head-size 2
python hashscan.py list
python hashscan.py stats 照片库
python hashscan.py delete 旧照片库

命令行给了参数的直接用，不再追问。重复文件夹默认是目标文件夹的子文件夹 duplicates，不再追问（可用 --dup-dir 改）。移动前会列出清单、输入 y 才移动；输入其他任意键取消移动（hash 已上传，文件没动）。列出/统计/删除项目用命令行：hashscan.py list、stats、delete。
